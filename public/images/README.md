# public/images/ — photos des défis

Déposez ici les visuels. Ils remplacent automatiquement les trames de couleur :
si le fichier n'existe pas, la trame duotone s'affiche à la place. Aucun code à
modifier.

## Noms de fichiers attendus

| Fichier | Où il s'affiche |
| --- | --- |
| `hero.jpg` | bandeau d'accueil, pleine largeur |
| `hp-01.jpg` | défi HP-01 — conteneurs réfrigérés |
| `hp-02.jpg` | défi HP-02 — déchets de navires |
| `hp-03.jpg` | défi HP-03 — données d'escale |
| `hp-04.jpg` | défi HP-04 — report modal fluvial |
| `hp-05.jpg` | défi HP-05 — submersion marine |
| `hp-06.jpg` | défi HP-06 — conformité NIS2 |
| `hp-07.jpg` | défi HP-07 — métiers portuaires |

Les noms sont en minuscules et sans accent. Sur le serveur de déploiement, la
casse compte : `HP-01.jpg` ne sera pas trouvé.

## Spécifications

- **Format** : JPEG. Le PNG est inutilement lourd pour une photo.
- **hero.jpg** : 2400 × 1200 px environ, cadrage horizontal large. Une couche
  sombre est appliquée par-dessus, donc une image plutôt claire fonctionne mieux.
- **hp-0X.jpg** : 1200 × 800 px environ. Elles s'affichent dans une carte de
  158 px de haut et en bandeau sur la page du défi : le sujet doit rester lisible
  une fois recadré en hauteur.
- **Poids** : viser moins de 300 ko par image. Sept images de 3 Mo rendent la
  page inutilisable en 4G.

## Droits

Ces images seront publiées sur un site institutionnel financé par l'État. Il faut
donc, pour chacune, une autorisation d'usage écrite : photothèque de HAROPA Port,
photothèque de l'ULHN, ou banque d'images sous licence commerciale. Une image
trouvée sur un moteur de recherche n'est pas utilisable.

Conservez la trace de l'origine et de l'autorisation de chaque fichier.
